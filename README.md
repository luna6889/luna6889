## 从一个小工具开始

### 抖音逐字稿导出 Skill

为内容研究准备材料：整理抖音视频的标题、逐字稿和互动数据，保存到本地文件或飞书多维表格。

- 运行环境：豆包工作。
- 输入：博主主页、单条视频或分享短链。
- 建议从最新 5 条视频开始，先检查结果。
- 当前公开内容：Skill 与参考文档；采集效果需在豆包工作中验证。
